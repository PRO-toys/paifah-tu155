Sources and study notes

This companion covers Lectures 8–13 of TU155 Elementary Statistics at Thammasat University, using handouts by Assoc. Prof. Nij Tontisirin. Course practice follows the six questions in the Final Practice Questions dated 16 November 2026.

    Quick notes in English

    • Confidence intervals: start at the sample estimate. Add and subtract a critical value times the standard error.
    • Hypothesis tests: write the null and alternative before calculating. The alternative determines the tail.
    • Paired data: calculate one difference per person or pair, then work with those differences.
    • Reporting: compare the p-value with the significance level and write a conclusion using the words from the question.

    For the complete handouts and workbooks, use the course materials provided by Thammasat University.
